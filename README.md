# موقع مبادرة روح

موقع عربي RTL قابل للإدارة بالكامل، يعمل بدون أي مكتبات خارجية باستخدام Node.js 22+ وSQLite المدمج.

## التشغيل على Mac

1. افتح Terminal داخل مجلد المشروع.
2. تأكد من Node 22 أو أحدث:
   ```bash
   node -v
   ```
3. شغّل الموقع:
   ```bash
   node server.js
   ```
4. افتح:
   - الموقع: http://localhost:3000
   - لوحة الإدارة: http://localhost:3000/admin

## أول تشغيل

عند فتح لوحة الإدارة لأول مرة سيطلب منك إنشاء **حساب المالك Owner**. لا يوجد اسم مستخدم أو كلمة مرور افتراضية داخل المشروع.

## الصلاحيات

- Owner: كل شيء + إضافة/إيقاف المسؤولين.
- Admin: المحتوى، الفعاليات، الإنجازات، الأسئلة، الأرقام، السلة، السجل.
- Editor: الفعاليات والإنجازات ورفع الصور.

## البيانات

- قاعدة البيانات تنشأ تلقائيًا في `data/rouh.db`.
- الصور المرفوعة تحفظ في `public/uploads/`.
- الحذف للفعاليات والإنجازات والأسئلة هو حذف آمن إلى سلة المحذوفات.
- يوجد سجل تعديلات داخل لوحة الإدارة.

## النشر لاحقًا

يمكن نشره على أي استضافة تدعم Node.js 22 مع قرص دائم (Persistent Disk). عند وضعه خلف HTTPS، شغّله مع:

```bash
NODE_ENV=production node server.js
```

> مهم: خذ نسخة احتياطية دورية من `data/rouh.db` و`public/uploads/`.
